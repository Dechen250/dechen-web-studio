## Objetivo

Receber logos, variações oficiais e materiais visuais da marca Renê Bradock.

## Arquivos atuais

| Arquivo | Uso |
|---------|-----|
| `logo-rene-bradock.png` | Logo circular — favicon, navbar compacta |
| `rene-bradock-hero.png` | Arte oficial (flyer) — hero, sobre, OG |

## Nomenclatura

- Minúsculas, hífen, sem acentos
- Prefixo `rene-bradock-` para variações novas (ex.: `rene-bradock-favicon.png`)

## Uso no site

Copiar para o repositório do site:

```text
public/logo-rene-bradock.png
```

Favicon derivado da logo oficial.

## Regra

Colocar **somente arquivos oficiais** entregues pelo cliente. Não inventar logos, fotos de obra ou materiais promocionais.

## Checklist

- [ ] Logo oficial presente
- [ ] Hero / flyer mapeado
- [ ] Favicon gerado a partir da logo
- [ ] Imagem Open Graph quando disponível
