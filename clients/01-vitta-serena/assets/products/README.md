# Produtos — como receber fotos

Crie **uma pasta por SKU** assim que o código estiver definido.

```text
products/
└── br-001/          ← exemplo de nome de pasta (SKU em minúsculas)
    ├── 01-principal.webp
    ├── 02-detalhe.webp
    ├── 03-uso.webp
    └── 04-embalagem.webp
```

## Ordem das imagens

| Arquivo | Uso no site |
|---------|-------------|
| `01-principal` | Card + primeira da galeria |
| `02-detalhe` | Close / acabamento |
| `03-uso` | Em uso ou referência de escala |
| `04-…` | Fecho, lateral, embalagem, composição |

## Antes de criar pastas

Não criar pastas com SKU inventado. Esperar a planilha oficial ou a definição pós-fornecedores.

Enquanto isso, deixe os originais em `../_inbox/` com uma lista (papel, mensagem ou CSV) ligando cada foto ao nome provisório da peça.
