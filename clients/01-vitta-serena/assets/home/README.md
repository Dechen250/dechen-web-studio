# Home — imagens da página inicial

**Tipo:** assets (staging) · **Status:** em andamento · **Versão:** 2.0

Índice: [../README.md](../README.md) · Guia completo: [../../04-assets.md](../../04-assets.md)

## Objetivo

Receber imagens usadas na homepage: hero, sobre e coleção em destaque.

## Arquivos esperados

| Arquivo | Uso |
|---------|-----|
| `hero.webp` | Peça real ou composição da marca |
| `sobre.webp` | Fundadora / bastidores / embalagem (com aprovação) |
| `colecao-destaque.webp` | Seleção principal do lançamento |

Formato preferencial: **WebP**.

## Nomenclatura

- Minúsculas, hífen, sem acentos
- Nomes fixos conforme tabela acima

## Regra

**Nunca inventar** cenas ou usar banco de imagem genérico como se fosse a coleção.

Hero deve transmitir delicadeza, uso real e elegância cotidiana com peças reais.

## Checklist

- [ ] Hero com peça ou composição real
- [ ] Imagem de sobre aprovada pela Gabi
- [ ] Coleção em destaque alinhada à planilha de produtos
- [ ] Cor fiel, fundo limpo, otimizado para web
