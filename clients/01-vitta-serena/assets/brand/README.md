# Brand — identidade visual

**Tipo:** assets (staging) · **Status:** em andamento · **Versão:** 2.0

Índice: [../README.md](../README.md) · Guia completo: [../../04-assets.md](../../04-assets.md)

## Objetivo

Receber logos, símbolo e favicon oficiais da Vitta Serena.

## Arquivos esperados

| Arquivo | Uso |
|---------|-----|
| `logo-principal.svg` | Logo horizontal principal |
| `logo-clara.svg` | Versão para fundos escuros |
| `logo-escura.svg` | Versão para fundos claros |
| `simbolo.svg` | Símbolo isolado |
| `favicon.png` | Favicon |
| PNG transparente em alta | Backup raster, se houver |

Opcional nesta pasta ou em `../cadastro/`: arquivo editável, guia de cores e tipografia.

## Nomenclatura

- Minúsculas, hífen, sem acentos
- SVG preferencial para logos
- Não recolorir, esticar ou alterar proporções

## Regra

Usar **somente versões oficiais aprovadas**. Nunca redesenhar ou inventar variações.

## Checklist

- [ ] Logo principal em SVG
- [ ] Versões clara e escura
- [ ] Símbolo e favicon
- [ ] Contraste testado em fundo claro e escuro
- [ ] Versão final confirmada pela Gabi
