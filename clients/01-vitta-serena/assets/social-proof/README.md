# Social proof — prova social

**Tipo:** assets (staging) · **Status:** em andamento · **Versão:** 2.0

Índice: [../README.md](../README.md) · Guia completo: [../../04-assets.md](../../04-assets.md)

## Objetivo

Armazenar depoimentos e imagens autorizadas para a seção de prova social do site.

## O que incluir

- Depoimentos textuais autorizados
- Fotos de clientes autorizadas
- Marcações do Instagram autorizadas

## Nomenclatura

- Minúsculas, hífen, sem acentos
- Nomes descritivos (ex.: `depoimento-maria.webp`)

## Regra

Incluir **somente com autorização explícita**. **Nunca inventar** depoimentos, avaliações ou fotos de clientes.

Se não houver conteúdo real, deixe vazio — a seção não entra no lançamento.

## Checklist

- [ ] Autorização por escrito de cada depoimento/foto
- [ ] Texto revisado pela cliente
- [ ] Imagem otimizada para web
- [ ] Seção oculta no site quando pasta estiver vazia
