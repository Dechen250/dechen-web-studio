# Cadastro de produtos

1. Copie `produtos-template.csv` para `produtos.csv`.
2. Preencha **somente** o que estiver confirmado.
3. Colunas vazias = ainda não definido (não inventar).
4. Em `imagem_01`, `imagem_02`, `imagem_03` use o caminho relativo após organizar, por exemplo:

```text
products/br-001/01-principal.webp
```

Categorias previstas (confirmar com a coleção):

- brincos
- colares
- pulseiras
- aneis
- kits-presentes

Valores de `disponivel`, `destaque`, `novidade`: `sim` ou `nao`.
