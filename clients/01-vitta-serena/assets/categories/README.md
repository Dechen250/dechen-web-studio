# Categories — imagens por categoria

**Tipo:** assets (staging) · **Status:** em andamento · **Versão:** 2.0

Índice: [../README.md](../README.md) · Guia completo: [../../04-assets.md](../../04-assets.md)

## Objetivo

Uma imagem representativa por categoria de produto, usada nos cards da home e navegação.

## Arquivos esperados

| Arquivo | Categoria |
|---------|-----------|
| `brincos.webp` | Brincos |
| `colares.webp` | Colares |
| `pulseiras.webp` | Pulseiras |
| `aneis.webp` | Anéis |
| `kits-presentes.webp` | Kits e presentes |

## Nomenclatura

- Minúsculas, hífen, sem acentos
- WebP preferencial

## Regra

Incluir categoria **somente se houver produtos reais** nela. Usar produto real da categoria — **nunca inventar** peças ou fotos genéricas.

## Checklist

- [ ] Uma imagem por categoria ativa
- [ ] Produto real da categoria em cada foto
- [ ] Proporção consistente entre categorias
- [ ] Categorias sem produto permanecem vazias
