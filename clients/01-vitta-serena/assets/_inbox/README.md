# Inbox — entrega bruta

**Tipo:** assets (staging) · **Status:** em andamento · **Versão:** 2.0

Índice: [../README.md](../README.md) · Guia completo: [../../04-assets.md](../../04-assets.md)

## Objetivo

Receber arquivos brutos antes da organização final. A DWS move e renomeia para as pastas definitivas.

## O que colocar aqui

- Fotos da câmera / celular (`IMG_…`, `DSC_…`)
- ZIP do ensaio
- Logos ainda sem nome final
- Qualquer arquivo que ainda não foi organizado

## Destino após organização

| Tipo | Pasta final |
|------|-------------|
| Logos | `../brand/` |
| Hero / sobre / coleção | `../home/` |
| Categorias | `../categories/` |
| Produtos | `../products/[sku]/` |
| Embalagem | `../packaging/` |
| Depoimentos | `../social-proof/` |

## Nomenclatura

Nesta pasta, qualquer nome temporário é aceito. Após organização, seguir as regras do [README principal](../README.md).

## Regra

**Nunca inventar** produtos, SKUs ou fotos. Se ainda não houver SKU definido, deixe os originais aqui com uma lista ligando cada foto ao nome provisório da peça.

## Checklist

- [ ] Arquivos soltos ou em ZIP identificável
- [ ] Lista de SKUs ou nomes provisórios, se aplicável
- [ ] Após organização, remover duplicatas desta pasta
