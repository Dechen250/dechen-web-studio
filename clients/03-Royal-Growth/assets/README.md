# Assets — índice

**Tipo:** staging · **Versão:** 2.0

Pack: [../04-assets.md](../04-assets.md) · [../00-projeto.md](../00-projeto.md)

## Estrutura

```text
assets/
├── _inbox/         ← materiais brutos do cliente
├── brand/          ← logo, favicon, manual
├── cases/          ← mídia dos cases autorizados
└── social-proof/   ← RD Diamond, selos, depoimentos
```

Checklist completo e pendências: [`04-assets.md`](../04-assets.md).

## Fluxo

1. Cliente envia arquivos em `_inbox/` (ou já renomeados na pasta final).
2. Organizar em `brand/`, `cases/` ou `social-proof/`.
3. Copiar para o repositório do site (`E:\DechenWebStudio\royal-growth`) quando o build existir.

## Regras

- Não publicar logo de case sem autorização
- Não inventar métricas ou depoimentos
- Preview pode usar placeholders marcados
