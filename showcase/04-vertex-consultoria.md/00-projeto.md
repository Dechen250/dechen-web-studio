# Projeto Conceito — Vertex Consultoria

## Objetivo

Criar um site institucional premium para uma consultoria fictícia que demonstre autoridade, clareza de método e conversão de leads.

## Sobre a Marca

### Nome

Vertex Consultoria

### Segmento

Consultoria estratégica para empresas em crescimento.

### Posicionamento

Consultoria que estrutura operação, decisões e crescimento com método — não discurso genérico de “agência”.

## Personalidade

- Autoridade
- Precisão
- Clareza
- Análise
- Confiança executiva

Nunca deve parecer genérica, “startup hype” ou visualmente igual à Barbearia Royal.

## Direção Visual

Site **escuro frio** (slate/carvão) + acento ciano. Tipografia sans geométrica forte (Syne). Hero tipográfico full-bleed com grade geométrica — sem foto de stock no centro.

## Estrutura

Hero → Método → Serviços → Resultados → Sobre → Contato → Footer

## CTA principal

Falar com consultor / solicitar diagnóstico (form → WhatsApp).
