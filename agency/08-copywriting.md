# Copywriting — Dechen Web Studio

**Tipo:** ops · **Status:** ativo · **Versão:** 2.0

Como escrevemos para a marca DWS e para projetos. Tom da marca: [Brand Guide](02-brand-guide.md). Em cliente com brief próprio (ex.: Royal Growth `SITE 2026/0.0`), **o brief do cliente manda**.

## Princípios

1. Clareza acima de persuasão agressiva
2. Uma ideia por bloco
3. Benefício concreto > adjetivo vazio
4. Nunca inventar fato comercial
5. CTAs explícitos e honestos

## Estrutura de página (padrão)

| Bloco | Conteúdo |
|-------|----------|
| Hero | Marca forte + uma headline + uma frase + grupo de CTA |
| Seção | Um propósito, um título, um apoio curto |
| Prova | Cases/depoimentos só com autorização ou flag demonstrativo |
| Conversão | Form / WhatsApp com microcopy clara |
| Footer | Contato real ou demonstrativo rotulado |

## Limites úteis

- Headline: preferir até ~10 palavras
- Apoio do hero: 1–2 frases
- Parágrafos de corpo: curtos; quebrar paredes de texto
- Meta title: ~50–60 caracteres · description: ~140–160

## Showcase vs cliente

| | Showcase | Cliente |
|---|----------|---------|
| Preços / reviews / métricas | Rotular **demonstrativo** | Só dados confirmados |
| Dados faltando | Inventar com flag clara de ficção | `[placeholder]` |
| Tom | Adequado ao segmento fictício | Brief do cliente |

## Microcopy

Estados de form: envio, sucesso, erro, campos obrigatórios. Mensagens de WhatsApp pré-formatadas quando forem o CTA principal.

## O que evitar

- “Não é X, é Y” em loop
- Jargão de marketing vazio
- Promessas médicas/financeiras sem base
- Reescrever copy aprovada do cliente para “vender mais”
