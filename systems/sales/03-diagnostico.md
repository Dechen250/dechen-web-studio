# Diagnóstico

**Tipo:** Etapa comercial · **Status:** ativo · **Versão:** 2.0

## Objetivo

Analisar informações da [Descoberta](./02-descoberta.md) e definir a melhor estratégia para o cliente. **Sem** desenvolvimento e **sem** proposta nesta etapa.

Posição no funil: [01-funil.md](./01-funil.md) — etapa 4, entre **Descoberta** e **Proposta**.

Pergunta central: *"Qual é a melhor solução para este cliente?"* — nem sempre coincide com o pedido inicial.

## Critérios de entrada e saída

| | Condição |
|---|----------|
| **Entrada** | Descoberta concluída; dados obrigatórios registrados |
| **Saída** | Objetivos, problemas, escopo, prioridades e estratégia validados internamente; pronto para [Proposta](./04-proposta.md) |

## Processo

```
Informações coletadas → Análise → Problemas → Oportunidades → Estratégia → Escopo recomendado → Proposta
```

## Análise do negócio

Avaliar:

- Modelo de negócio e posicionamento
- Público-alvo e diferenciais
- Concorrência
- Presença digital, comunicação e objetivos

## Diagnóstico da presença digital

Analisar:

- Site atual · Redes sociais · Google
- SEO · Performance · Identidade visual
- Experiência do usuário · Conversão

**Pergunta-chave:** *"O que está impedindo este negócio de crescer?"*

## Problemas identificados

Registrar para cada item:

| Campo | Exemplo |
|-------|---------|
| Problema | Site lento |
| Impacto | Alta taxa de abandono |
| Prioridade | Alta |

## Oportunidades

Exemplos: melhorar conversão · Landing Pages · SEO · Performance · Automações · Integrações · Identidade visual · UX

## Definição da estratégia

Após análise, documentar:

- Objetivo principal
- Estratégia recomendada
- Escopo inicial
- Prioridades
- Cronograma estimado

## Solução recomendada

Personalizada ao diagnóstico. Exemplos:

- Landing Page · Site Institucional · Portfólio
- Sistema interno · Redesign · Manutenção · SEO

A recomendação resolve o problema do cliente, não apenas atende ao pedido inicial.

## Critérios de aprovação interna

Antes de seguir para proposta, confirmar:

- [ ] Objetivos compreendidos
- [ ] Problemas identificados
- [ ] Escopo definido
- [ ] Prioridades estabelecidas
- [ ] Estratégia validada internamente

## Resultado esperado

Clareza suficiente para elaborar [Proposta](./04-proposta.md) personalizada, alinhada aos objetivos e baseada em estratégia sólida. A proposta é consequência do diagnóstico, nunca o contrário.
